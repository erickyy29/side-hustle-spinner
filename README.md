# Side Hustle Spinner

A "random side hustle" slot reel for UGC and short-form video: a single `index.html` you can film off a laptop screen for short-form video.

Open `index.html` in Chrome.

| Key | Action |
| --- | --- |
| Space / click | Spin |
| 1–9 | Secretly preset the next result (1 = first item) |
| R | Reset |
| F | Fullscreen |
| G | Green screen (#00FF00) for keying |
| M | Sound on/off |
| E | Edit the list (one item per line) |

The default list is the `ITEMS` array at the top of `index.html`. Edits made with E are saved in the browser.
